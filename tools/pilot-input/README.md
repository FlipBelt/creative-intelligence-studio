# 合成试点输入包离线门禁

对应 [FBC-267](https://linear.app/j21nianyi/issue/FBC-267)，属于 FBC-236 的技术准备，服务 FBC-10/11 的输入整理。它是 CIS 的本地契约，不是知识库/DAM 已有远端 API，也不是 Penpot 的导出实现。

## 运行

仓库固定 Node.js 24.15.0 / npm 11.19.0，使用根锁文件已有依赖，无需新增服务或密钥。

```sh
npm run test:pilot-input
node tools/pilot-input/validate.mjs --manifest tests/pilot-input/fixtures/valid/manifest.json
```

只读取显式 manifest 及其声明的本地文件；默认以 manifest 所在目录为根，可通过 `--root <目录>` 显式指定。不会扫描目录或从清单主动访问 URL/NAS，不读取环境凭据、不写回输入包；CLI 参数拒绝 UNC、设备命名空间及 URL。调用者必须选择可信的本地目录，不使用映射网络盘。样例全部为合成测试数据，Git 属性禁用其换行转换以保留固定摘要。

输出只包含门禁状态、固定 scope、合成分类、输入摘要、错误代码/字段及未评估能力，不回显资料正文、许可记录值或本地绝对路径。退出码 0 表示合成包内部校验通过，1 表示输入/文件/许可记录不符合契约，2 表示 CLI 参数不正确。

## 校验范围

- `schema_version` 固定、`data_classification=synthetic`，严格拒绝未知字段。
- Brief、知识、素材都有固定版本、相对路径和 SHA256；知识另有 Release，素材另有 size/MIME、来源标识和显式父版本（原创可为 null）。
- 按同一文件句柄读取实际字节并比对摘要及大小。
- 用途与处理方必须出现在许可记录允许范围内；未知、过期、撤销及缺少证据引用拒绝。
- `confirmation.kind=synthetic_fixture` 与全部输入摘要绑定；更改版本、内容、用途或许可记录后，旧确认失效。此标记不能充当真人批准。
- 限制 manifest、单文件、文件总量及知识/素材数量；拒绝绝对路径、UNC、路径穿越、ADS、符号链接/junction 及非普通文件。精确限制和完整字段以 `contracts/pilot-input.mjs` 为准。

MIME 只核对声明值允许列表，不解码或认证媒体格式。调用者须控制输入目录，运行时不得并发替换其目录和文件；映射盘是否位于网络上不能由 Node 路径字符串判断。路径检查不是敌对共享文件系统的隔离设施。

## 结果边界与后续

分类、来源和许可均来自本地记录；程序核对一致性，不能证明记录真实性、版权许可、服务器 ACL 或人员身份。合成通过不允许真实企业资料进入试点，也不证明第三方处理已获许可、实际备份恢复、业务 UAT 或生产可用。

更换真实包必须先补 FBC-10 的已核商品与用途素材、FBC-236 的实际权限/资料和恢复证据，再单独实施真实资料接入。本轮不改变现有 Mock MCP 契约、预览页面、Sites 或 Penpot 原文件。Penpot PR #12525 继续等待上游。
