## 基本设计与 SDK 分离

既有 FBC-7 证据包括原生对象/中文文本、保存后离开重开、原生读取与受控断开重连，以及 SVG 和原生 UI 归档恢复。历史目标保存重开记录为 677 对象、317 原生文本；UI 归档隔离导入、离开重开与二次导出比较过对象/文本/几何/样式/路径及两项媒体。对应原始记录保留在 FBC-7 与本机 Penpot 集成验证目录。

这些证据支持当前基本设计与手工备份交付，不证明 SDK 整文件自动导出、单文件只读凭据、真实密钥撤销或新增角色权限。SDK 最后一次托管实际失败为 2026-10-22 的 `No matching clause`，不是本轮新测。上游 [PR #12525](https://github.com/penpot/penpot/pull/12525) 与 [#11554](https://github.com/penpot/penpot/issues/11554) 由 [FBC-286](https://linear.app/j21nianyi/issue/FBC-286) 追踪；只有新可用修复或可执行反馈才触发验证，不重复无变化轮询。

FBC-286 后续必须导出新 SDK 字节、核对摘要/CRC/JSON/对象/文本/媒体，并在隔离位置导入、离开重开、二次导出；历史 UI 归档不能替代。普通设计可继续采用手工原生备份路径。
