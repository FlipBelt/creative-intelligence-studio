# 页面与交互契约 V0.1

状态：规划草案。全部路由为拟定路由，未实现。共享视觉规则仅见 ../DESIGN.md。

## 1. 信息架构与主旅程

全局：项目 / 参考库 / 资产库 / 任务；设置按权限显示。首页以创建和恢复项目为主，不放无来源统计。
项目内部保留 V0.5 十阶段，但按三个业务组组织：
理解：产品、创意需求；构思：参考发现、参考组合、创意分析、创意方向、创意板；制作：生产、审核、最终资产。
阶段导航可自由查看已存在内容；只有会产生下游数据的操作检查依赖。禁止把所有页面锁成无法回看的向导。
主路径：建项目→绑定产品并检查来源→保存确认需求→加入手动参考→分析→对比方向→确认→生成→人工审核→保存Final。
辅助AI面板只协助当前阶段。用户确认才将建议写入业务对象；聊天历史不是方向或生产协议的真源。

## 3. 通用状态与错误

| 状态 | 呈现 | 动作/约束 |
|---|---|---|
| 加载 | 与内容结构相符的骨架、加载文字 | 不显示占位数字为真实数据 |
| 初次为空 | 尚无对象、创建价值 | 一个明确创建入口 |
| 筛选为空 | 当前条件无结果 | 清除筛选，保留输入 |
| 成功 | 在原位置显示结果和保存时间 | 可跳转产物；不能只靠短暂Toast |
| 校验失败 | 字段错误+页首摘要 | 聚焦首个错误；保留所有可恢复输入 |
| 服务失败 | 用户可理解原因、重试、关联请求ID | 不泄露堆栈；重试不能重复收费 |
| 权限不足 | 无权访问及返回入口 | 不泄露名称/缩略图；不伪装为空 |
| 会话过期 | 登录恢复入口 | 安全保存非敏感草稿，返回原项目 |
| 版本冲突 | 本次输入与最新版本提示 | 用户重新加载/合并，禁止最后写入静默覆盖 |
| 知识过期 | 使用版本、读取时间、更新提示 | 更新需重新确认下游，旧结果保留 |
| NAS/模型未配置 | 明确缺少的能力 | 指向有权限管理员；不展示假成功 |
| 断网/事件中断 | 状态暂未更新、最近更新时间 | 重连取快照；不将断连当取消 |
| 部分失败 | 成功与失败项分别列出 | 仅重试失败项，保留已成功产物 |

## 4. 状态名称与动作映射

PENDING 待提交；QUEUED 排队中；RUNNING 处理中；WAITING_REVIEW 待确认；RETRYING 正在重试；SUCCEEDED 处理完成；FAILED 处理失败；CANCELLED 已取消。
PENDING含义需与最终后端命令契约一致：如创建即入队，则仅内部短暂出现，不制作虚假待提交按钮。
WAITING_REVIEW属于执行流程检查点，最终产物人工评审是Review对象，界面需说明具体待确认事项。
取消请求发出后显示“正在请求取消”；收到终态才“已取消”。供应商不可取消时说明仍可能完成，并提供完成后处理方式。
重试显示作用范围与可能成本；无供应商估价显示“费用暂不可估算”，不能显示0元。首次生产确认包括输出数量、规格、已知费用/预算与输入版本。

## 5. 事实、比较与评审

产品字段就近展示来源等级，展开见来源ID/版本/时间/项目限定。未知字段无自动补值。
参考组合维度包括摄影、光线、色彩、动态、产品表达；P2权重明确为强参考1、弱参考0.5、忽略0、禁止迁移-1，并解释-1是约束，不是负分推荐。
方向比较固定维度：产品、意图、品牌、真实性、原创性、可执行性、成本与风险。真实表现分仅有来源时显示，缺值不参与默认总分。
审核并置原始产品素材与生成结果；AI意见可展开依据；人工通过、淘汰、修改、收藏分别记录，收藏不等于通过。
局部重生成创建新版本且只在Adapter支持时提供，明确修改区域、保留部分和影响范围。Final锁定已审核版本。

## 6. 导航、表单与媒体细节

URL保留项目、阶段、筛选与选中对象，可刷新和分享给有权限成员；返回恢复滚动和选择。
输入提交使用原生表单语义；中文输入法组合期间Enter不得提前提交。破坏性动作禁止绑定无确认的单键快捷键。
Dialog打开后聚焦标题或首个必要字段；焦点限制在弹层；Escape关闭非强制流程；返回触发按钮。脏表单退出需选择保留/放弃。
上传分别显示待上传、上传中、处理、可用、失败；字节百分比仅来自上传事件；服务端分析进度单独显示。
拖拽必须有“选择文件”和键盘替代；格式/大小限制由真实后端能力提供。媒体网格选择框与打开预览分离。
历史版本只读，可复制为新版本；删除及保留策略尚未批准，MVP优先归档，不规划隐式永久删除。

## 2026-09-21：简易创作交互（覆盖首版十阶段主导航）
已实现hash路由 /create/image、/create/copy、/create/video；/library集中管理项目。首页三种媒体入口后，提供对应场景与可编辑示例。只要求填写需求；项目名、受众、产品背景可展开补充。默认项目名来自需求前18字。
默认主路径：选择媒体 → 描述需求 → 确认预设方向 → 查看与修改。参考、分析、创意板作为可选专业工具。旧项目及旧阶段URL保留兼容，默认呈现三步流程。
文案预览为本地模板，允许修改后另存新版本；旧版本留在历史记录。人工通过后允许导出。未保存修改离开提示，制作新版本前要求保存。图片／视频明确提示服务未接入，可保留需求和方向并导出Markdown计划，不展示假媒体或假生成进度。
新建简易项目带simple=true。无需虚构产品绑定或参考也能确认方向，但需求确认、归档限制、输入版本失效、审核版本检查仍有效。缺失事实保持未知。既有专业领域校验保留，新手保存需求后切换为简易输入契约；真实API/知识/生成接入仍未实现。
